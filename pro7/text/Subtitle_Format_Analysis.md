## 各格式说明

### 1. SRT（SubRip）- 13个文件
最常见的纯文本字幕格式，由编号、时间轴和台词组成：

```
1
00:00:01,000 --> 00:00:04,000
第一行字幕
第二行字幕

2
00:00:05,000 --> 00:00:08,000
下一段字幕
```

- 优点：体积小、易编辑、兼容性强
- 缺点：不支持样式（颜色、字体、位置）

### 2. ASS（Advanced SubStation Alpha）- 26个文件
功能强大的高级字幕格式，支持丰富的样式和特效：

```
[Script Info]
Title: House of Cards S01E01
ScriptType: v4.00+

[V4+ Styles]
Format: Name, Fontname, Fontsize, PrimaryColour, ...
Style: Default,Arial,20,&H00FFFFFF,...

[Events]
Format: Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text
Dialogue: 0,0:00:01.00,0:00:04.00,Default,,0,0,0,,第一行字幕
```

- 优点：支持颜色、位置、移动、字体粗细等特效
- 缺点：文件体积比 SRT 大

### 3. SUB + IDX（VobSub）- 13组（26个文件）
从 DVD/BluRay 提取的图像字幕，通常配合使用：

- `.idx`：索引文件，存储时间轴和语言信息（纯文本，可查看）
- `.sub`：图像数据文件（二进制，包含压缩的位图）

格式示例（.idx 文件头）：
```
# VobSub index file, pid 1011
# Language: chi
index: 0, start: 0:00:01.01
index: 1, start: 0:00:03.89
...
```

- 优点：保留原始视觉效果，不丢字体
- 缺点：无法直接编辑文字，不能搜索，不能机翻

### 4. PDF - 1个文件
`House.Of.Cards.2013.S01.台词对白.pdf`——纸牌屋第一季全部台词的对白文本版本，适合阅读和搜索。

## 电视剧字幕格式现状

### 下载市场主流格式

| 格式 | 地位 | 说明 |
|------|------|------|
| **SRT** | 🥇 最普遍 | 90%以上的下载字幕是SRT，兼容所有播放器 |
| **ASS** | 🥈 常见 | 通常用于有特效、有弹幕感设计的字幕组作品 |
| **SUP** | 🥉 蓝光碟 | 蓝光原盘自带，图像+复用流，普通下载少见 |

### 各平台来源差异

| 来源 | 常见格式 | 特点 |
|------|----------|------|
| 字幕组发布（射手网/OpenSubtitles等） | SRT为主 | 追求最大兼容，样式简单 |
| 压制组整合（RARBG/GB/Roars等） | ASS居多 | 嵌入式样式更美观，但有时影响性能 |
| 蓝光原盘 | SUP+ASS双轨 | 画面字幕 + 可切换文本字幕 |
| 流媒体平台（Netflix/Disney+等） | DFXP/TTML/VTT | 数字发行专用，带版权保护 |

### 实际情况

大多数电视剧字幕**以SRT为主**，原因是：
1. **播放器支持最广**：Kodi、VLC、PotPlayer、Infuse、Emby、Jellyfin 全部原生支持
2. **压制/分享最省心**：文件体积小，嵌入简单
3. **编辑最方便**：用记事本就能改错

ASS则更多出现在：
- 动漫字幕（需要逐字特效）
- 电影字幕（常有OP/ED歌词特效）
- 某些字幕组有意保留样式设计

电视剧本身不需要复杂字幕特效，所以**SRT是电视剧领域毫无争议的主流**。

## 常见字幕格式一览（扩展）

### 纯文本类

| 格式 | 全称 | 特点 |
|------|------|------|
| **.srt** | SubRip | 最通用，纯文本，兼容性强 |
| **.sub** | MicroDVD | 用 `{起始帧}{结束帧}` 标记时间，帧数而非时间戳 |
| **.ssa** | SubStation Alpha | ASS 前身，样式支持较基础 |
| **.usf** | Ultra Subtitle Format | XML 基底，支持更复杂特效 |

### 高级样式类

| 格式 | 全称 | 特点 |
|------|------|------|
| **.ass** | Advanced SubStation Alpha | 支持颜色、位置、移动、特效，是目前功能最强的文本字幕 |
| **.ssf** | Structured Subtitle Format | 索尼 PS3/蓝光专用 |

### 图像类

| 格式 | 说明 |
|------|------|
| **.sub + .idx** | VobSub（DVD/BluRay 提取） |
| **.sup** | HD-DVD / BluRay 图像字幕（复用信息流） |
| **.son** | 竖版字幕，模拟电视时代的图像字幕 |

### 广播/专业格式

| 格式 | 全称 | 说明 |
|------|------|------|
| **.stl** | EBU STL | 欧洲广播联盟标准，用于电视播出 |
| **.pac** | PAC | 极坐标编码，多用于亚洲电视广播 |
| **.scc** | Scenarist Closed Caption | 欧美闭路字幕标准（.scc 用于 DVD 和广播） |
| **.dfxp / .ttml / .xml** | Distribution Format Exchange Profile / Timed Text | 互联网电视常用，可带样式 |
| **.cpt** | Captionate | WebVTT前身 |

### 时间歌词类

| 格式 | 说明 |
|------|------|
| **.lrc** | Lyrics | 音乐歌词同步格式 `[mm:ss.xx]` 时间标签 |
| **.kly** | 卡拉OK歌词 | 类似LRC但支持逐字高亮 |

### 网页/流媒体格式

| 格式 | 说明 |
|------|------|
| **.vtt** | WebVTT | HTML5 标准，Web 视频字幕 |
| **.srv** | YouTube 导出格式 | 类似SRT，带简单样式 |
| **.sbv** | YouTube 字幕 | Google 的SRT变体 |

### 特殊用途

| 格式 | 说明 |
|------|------|
| **.json** | JSON 字幕 | 某些播放器自定义格式 |
| **.pdf** | 对白文本 | 纯阅读，无时间轴 |

## 内容来源分析

字幕来自两个不同压制组：
- `[zmk.pw]`：同时提供 .ass 和 .srt 两种格式（简体+英文双语）
- `1667973904345`（文件夹名）：只有 .ass 格式（来自 RARBG 压制组）
- `Subs/`：VobSub 版本（来自 rovers 压制组）

## 格式对比总结

| 格式 | 可编辑 | 样式支持 | 体积 | 搜索性 | 常见场景 |
|------|--------|----------|------|--------|----------|
| SRT | ✅ 容易 | ❌ 无 | 小 | ✅ | 通用下载 |
| ASS | ✅ 容易 | ✅ 丰富 | 中 | ✅ | 动漫/特效字幕 |
| SSA | ✅ 容易 | ✅ 基础 | 中 | ✅ | 老字幕 |
| SUB/IDX | ❌ 图像 | 原始样式 | 大 | ❌ | DVD/BluRay |
| VTT | ✅ 容易 | ✅ 基础 | 小 | ✅ | 网页/HTML5 |
| LRC | ✅ 容易 | ❌ 无 | 很小 | ✅ | 音乐歌词 |
| STL | ⚠️ 需专业工具 | ✅ | 中 | ✅ | 电视广播 |
| PDF | ❌ | ❌ | 大 | ✅ | 台词对白 |
