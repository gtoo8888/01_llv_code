## 工作流程

### 1. 获取数据

在淘票票专业版上搜索电影，找到单片每日票房明细页面，将HTML保存到 `01_raw/` 下对应的年份目录中。

### 2. 文件命名规范

```
序号_YYYYMMDD_电影名.html
```

- 序号：按当年票房排名，补零到两位（01, 02, ... 20）
- 日期：上映日期，8位数字
- 电影名：中文全名

示例：`01_20240210_热辣滚烫.html`

### 3. 转换数据

```bash
python taopiaopiao_to_csv.py <输入路径>
```

- 输入可以是目录或单个文件
- 输出自动到 `02_csv/` 目录（`01_raw` -> `02_csv`）
- 文件名保持不变，后缀从 `.html` 变为 `.csv`
- 电影名从文件名自动提取，写入CSV首列

### 4. 分析数据

CSV数据包含26个字段，涵盖每日票房、场次、人次、票价、上座率、退票率等维度。可用于后续的数据分析。

## 开发记录

- 淘票票的票房数据表格HTML结构固定，使用 `tbody.cm-table-tbody` + `tr.cm-table-row` 定位数据行
- 日期列包含星期和标签（点映/上映首日），需要分别提取
- 数据格式多样：万单位("1.0万")、百分比("0.1%")、区间值("<0.1%")、空值("--")
- 百分比列保留原始字符串（含%号），方便直接阅读；数值列转为float便于计算
- 文件名编码了序号和上映日期，实现"无参数"调用：脚本从文件名自动提取电影信息
- 输出路径通过 `01_raw` -> `02_csv` 替换实现，一年份一个子目录便于管理
